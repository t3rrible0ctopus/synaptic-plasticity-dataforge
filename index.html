Synaptic Plasticity as Short-Term Memory

Watch a memory form in synaptic weights — then see how interference erodes it.

THE IDEA

Memory doesn't need a dedicated storage slot.

When cat and meow repeatedly occur together, connections between active neurons strengthen. Later, unrelated activity changes those same connections, causing the memory to fade.
