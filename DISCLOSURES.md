## Code

The core implementation of the synaptic plasticity model was developed for this project.

The model is a deliberately simplified educational implementation of Hebbian learning with synaptic decay. It is not an official implementation of BDH or BDH-CQ.

The main implementation is contained in:
- `hebbian_core.py`
- `experiments.py`
- `test-model.py`

The web-based interactive component is contained in:
- `index.html`
- `app.js`
- `style.css`

## BDH / BDH-CQ Attribution

The project discusses BDH and BDH-CQ as related research directions involving changing internal state, recurrent computation, and inference-time memory.

This project does **not** reproduce the official BDH or BDH-CQ architectures.

The synaptic plasticity simulation is an independent educational toy model designed to make the underlying mechanism easier to visualize and manipulate.

## Limitations and Transparency

This project intentionally simplifies biological synaptic plasticity.

In particular:
- The neuron representations are hand-designed.
- The word-to-neuron mapping is deterministic rather than learned.
- The Hebbian update rule is simplified.
- The network is extremely small compared with biological neural systems.
- The model does not claim to reproduce biological memory.
- The model does not claim to reproduce BDH or BDH-CQ.

The purpose of the project is to demonstrate the relationship between recent activity, synaptic-strength changes, interference, decay, and short-term memory in an interpretable computational setting.
